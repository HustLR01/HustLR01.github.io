About

Rigorous systems understanding. Bold engineering execution.

My trajectory through Computer Engineering is fueled by an intense drive to dissect, challenge, and master complex computing systems at every layer. This is why I approach Cybersecurity not as a narrow specialization, but as an interconnected discipline where true robustness requires complete visibility: from bare-metal kernel mechanics and operating system primitives to automated access control policies and data-level security.

I approach vulnerability research and exploit mechanics with systematic engineering rigor: isolating root causes, tracing control-flow deviations, and mapping system attack surfaces. In parallel, my work bridges security engineering with applied machine learning through the development of a deep learning pipeline to automate data protection and policy governance.

Whether weaponizing an Android kernel vulnerability down to privilege and context escalation, or deploying deep learning models to automatically enforce Mandatory Access Control across enterprise data, my standard is uncompromising.

02

Android Remote Root Privilege Escalation PoC

A Proof of Concept exploit chaining a malicious .apk backdoor with a sophisticated weaponization of a Use-After-Free (UAF) Kernel vulnerability in the Android Binder IPC subsystem. The exploit does not merely set the uid and gid to 0 (root) but also, crucially, allows to elevate the SELinux context from untrusted_app to root (su).

Kernel Vulnerabilities · Backdoors · SELinux context elevation · Educational Ethical Hacking · System-level Mobile Security Analysis through Red Teaming · Exploit Development · Privilege Escalation
